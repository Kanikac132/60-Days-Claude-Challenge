# Day 37 - Task Compass Simulator

## Overview

For Day 37 of the AI Challenge, I developed an interactive **Task Compass Simulator** that explores workplace decision-making, task ownership, routing, and collaboration scenarios.

The application helps users understand how responsibilities are assigned, how tasks move between teams, and how collaboration decisions impact organizational performance.

## Features Implemented

* Workplace type selection
* AI-generated task management scenarios
* Stage 1: Who Owns This? challenge
* Stage 2: Task Routing challenge
* Stage 3: Collaboration Challenge
* Organizational Thinking Dashboard
* Performance insights and feedback
* Replay with different workplace environments

## Technologies Used

* HTML
* CSS
* JavaScript
* AI-assisted development using Claude

## Learning Outcomes

* Learned how AI can simulate workplace workflows
* Understood concepts of ownership and responsibility mapping
* Explored task management and collaboration strategies
* Improved skills in creating interactive decision-based applications
* Learned how dashboards can represent organizational insights


## Conclusion

This project demonstrated how AI-powered simulations can help users understand workplace processes, improve collaboration skills, and practice better decision-making in organizational environments.
