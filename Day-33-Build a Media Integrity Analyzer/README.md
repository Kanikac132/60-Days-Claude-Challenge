# Day 33 - Media Integrity Analyzer

## Overview

For Day 33 of the AI Challenge, I developed an interactive **Media Integrity Analyzer**, an AI-assisted application focused on analyzing media content, detecting emotional manipulation, and improving awareness of information quality.

The application provides challenges that help users understand how headlines and emotional techniques can influence perception.

## Features Implemented

* Customizable color theme selection
* Headline Detective challenge
* Headline analysis system
* Improved headline rewriting
* Emotion Detector challenge
* Emotional manipulation technique analysis
* Live Media Integrity metrics
* Final Media Integrity Dashboard
* Randomized scenario replay functionality

## Technologies Used

* HTML
* CSS
* JavaScript
* AI-assisted development using Claude

## Learning Outcomes

* Learned how AI can assist in media analysis
* Understood patterns behind misleading or emotionally driven content
* Explored digital literacy and responsible AI concepts
* Improved understanding of interactive application development
* Learned how dashboards can present analytical insights effectively


## Conclusion

This project demonstrated how AI-powered tools can help users critically evaluate digital content, recognize manipulation techniques, and develop better media awareness.
