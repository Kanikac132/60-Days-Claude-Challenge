# Day 31 - AI Supply Chain Control Tower

## Overview

For Day 31 of the AI Challenge, I developed an interactive **AI Supply Chain Control Tower** application that simulates real-time supply chain monitoring and decision-making.

The application allows users to monitor operational alerts, prioritize incidents, select corrective actions, and analyze how decisions impact key business performance indicators.

## Features Implemented

* Real-time operational alert monitoring
* Incident prioritization based on urgency
* Corrective action selection
* KPI impact visualization after decisions
* Multi-alert management system
* Operational performance tracking
* Final performance dashboard
* Scenario replay for improving results

## Technologies Used

* HTML
* CSS
* JavaScript
* AI-assisted development using Claude

## Learning Outcomes

* Learned how AI can support operational monitoring systems
* Understood supply chain incident management workflows
* Explored KPI-based decision-making
* Learned how control tower systems improve visibility and response time
* Improved skills in building interactive AI-assisted applications


## Conclusion

This project demonstrated how AI-powered control towers can help organizations monitor operations, identify risks, and make data-driven decisions to improve supply chain performance.
