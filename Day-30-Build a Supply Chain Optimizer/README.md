# Day 30 - Supply Chain Optimizer

## Overview

For Day 30 of the AI Challenge, I created an interactive **Supply Chain Optimizer**, a React-based application that simulates supply chain planning and optimization decisions.

The application allows users to make strategic decisions related to suppliers, factories, warehouses, transportation, and inventory management while observing how these choices affect business performance.

## Features Implemented

* Beginner-friendly supply chain introduction
* Random company profile generation
* Supplier strategy selection
* Factory location decision
* Warehouse strategy selection
* Transportation method selection
* Inventory strategy optimization
* Real-time business metric updates
* Final optimization dashboard
* Overall Supply Chain Score calculation
* Strengths and weaknesses analysis
* Risk identification
* Improvement recommendations
* Multiple scenario replay with different companies

## Technologies Used

* React
* HTML
* CSS
* JavaScript
* AI-assisted development using Claude

## Learning Outcomes

* Learned how supply chain decisions influence business performance
* Explored optimization and decision-support concepts
* Understood the importance of balancing cost, efficiency, and risk
* Improved knowledge of React-based interactive applications
* Experienced AI-assisted application development


## Conclusion

This project demonstrated how AI-powered simulations can help users understand complex business operations and practice strategic decision-making through interactive experiences.
